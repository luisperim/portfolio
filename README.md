**Curso:** Engenharia de Software — UTFPR (Campus Dois Vizinhos)

## Objetivo

Atividade prática de desenvolvimento incremental de um site pessoal dividido em três etapas:

1. **Etapa 1 (HTML):** Estruturação semântica do conteúdo utilizando apenas HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<form>` e `<footer>`).
2. **Etapa 2 (CSS):** Separação entre estrutura e apresentação visual com arquivo CSS externo (`style.css`), aplicação de cores, tipografia, bordas, espaçamentos (Box Model) e estados `:hover`.
3. **Etapa 3 (Responsividade):** Adaptação do layout seguindo a estratégia *Mobile First*, utilizando Flexbox, CSS Grid e Media Queries para diferentes tamanhos de tela (Mobile `~375px`, Tablet `~768px` e Desktop `>= 1200px`).
